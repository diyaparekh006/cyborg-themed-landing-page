# NEO//GEN — Cyborg-Themed Landing Page
Responsive fictional landing page made with HTML, CSS, and JavaScript.

## Run it
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Publish on GitHub
1. Create a public repository named `cyborg-themed-landing-page`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. To publish the website, go to **Settings → Pages**, select branch `main` and folder `/ (root)`, then save.

## Demo video
Record 30–60 seconds showing the homepage, scrolling through each section, and testing the mobile menu. Upload the recording to Google Drive and set General access to **Anyone with the link — Viewer**.
